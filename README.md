# My Capstone Project

This repository contains my engineering internship capstone project—a full-stack web application built with Node.js and vanilla JavaScript.

## Features

- **Responsive web UI** — HTML5, CSS3, and ES6+ JavaScript with no framework lock-in
- **Node.js server** — Backend logic and tooling powered by Node.js (LTS)
- **Modular codebase** — Clean, maintainable structure suitable for capstone review and iteration
- **Standard npm workflow** — Install dependencies, build, and run with familiar commands

## Prerequisites

Before you begin, ensure the following are installed on your machine:

| Requirement | Version / Notes |
|-------------|-----------------|
| [Node.js](https://nodejs.org/) | LTS (18.x or later recommended) |
| npm | Bundled with Node.js |
| [Git](https://git-scm.com/) | For cloning and version control |

## Stack

- **Runtime:** Node.js (LTS)
- **Frontend:** HTML5, CSS3, JavaScript (ES6+)

## Getting Started

To run the project locally:

1. Clone this repository.
   ```bash
   git clone https://github.com/your-username/my-capstone-project.git
   cd my-capstone-project
   ```
2. Install dependencies (once `package.json` is added).
   ```bash
   npm install
   ```
3. Start the application (once an entry point is configured).
   ```bash
   node index.js
   ```
